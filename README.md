# neuroVSalgo: Сравнительный анализ алгоритмических и нейросетевых методов решения задачи о назначениях в высоконагруженных системах

## Аннотация

Настоящий научно-исследовательский проект посвящен сравнительному вычислительному анализу методов решения классической линейной задачи о назначениях (Linear Sum Assignment Problem, LSAP) в контексте требований высоконагруженных диспетчерских платформ реального времени (SLA $\le 50\text{--}100$ мс).

В рамках проекта реализован модульный программный комплекс для верификации и сопоставления двух парадигм:
1. **Классические точные алгоритмы комбинаторной оптимизации**, функционирующие на базе скомпилированных C/C++ библиотек (модифицированный алгоритм Куна-Манкреса / Джонкера-Волгенанта в SciPy, аукционный алгоритм Берцекаса в Google OR-Tools).
2. **Нейросетевая аппроксимация (Deep Learning)** на базе инвариантного к размерности графового энкодера (`GraphContextEdgeMLP`), дифференцируемого слоя нормализации матриц к двоякостохастическому виду (`Sinkhorn Layer`) и параллельного жадного проекционного декодера на архитектуре NVIDIA CUDA (PyTorch).

## Математическая постановка задачи

Линейная задача о назначениях формулируется следующим образом:

$$\min_{X \in \Pi_N} \sum_{i=1}^N \sum_{j=1}^N C_{ij} X_{ij}$$

при ограничениях:

$$\sum_{j=1}^N X_{ij} = 1, \quad \forall i \in \{1, \dots, N\}$$

$$\sum_{i=1}^N X_{ij} = 1, \quad \forall j \in \{1, \dots, N\}$$

$$X_{ij} \in \{0, 1\}, \quad \forall i, j \in \{1, \dots, N\}$$

где:
* $N$ — размерность задачи (количество исполнителей и задач);
* $C \in \mathbb{R}^{N \times N}_{+}$ — матрица стоимости (дистанция, время отклика, задержка);
* $X \in \{0, 1\}^{N \times N}$ — бинарная матрица назначений из множества матриц перестановок $\Pi_N$.

В нейросетевой постановке дискретное ограничение релаксируется до политопа Биркгофа $\mathcal{B}_N$ (множества дважды стохастических матриц), а дискретное биективное отображение восстанавливается на этапе постобработки проекционным декодером.

## Исследуемые солверы

1. **SciPy Hungarian (`ScipyHungarianSolver`)**
   * Реализация алгоритма Куна-Манкреса / модифицированного метода Джонкера-Волгенанта на языке C (`scipy.optimize.linear_sum_assignment`).
   * Теоретическая временная сложность: $O(N^3)$.
   * Выполняется без накладных расходов интерпретатора в едином адресном пространстве памяти.

2. **Google OR-Tools (`OrToolsSolver`)**
   * Промышленная C++ реализация аукционного алгоритма Берцекаса ($\varepsilon$-Complementary Slackness, `SimpleLinearSumAssignment`).
   * Используется как эталон глобальной оптимальности (Ground Truth).

3. **Neural Sinkhorn (`NeuralSolver`)**
   * Архитектура: `GraphContextEdgeMLP` $\to$ `Log-domain Sinkhorn Normalization` $\to$ `Greedy Projective Decoder`.
   * Полностью инвариантна к размерности $N$ за счет перестановочно-эквивариантной схемы обработки ребер и узлов двудольного графа.
   * Аппаратное ускорение на тензорных ядрах NVIDIA GPU.

## Результаты экспериментов

Испытания проводились на сетке размерностей $N \in [10, 1000]$ на трех типах распределений стоимостей:
* **Spatial 2D:** Евклидовы расстояния между агентами и задачами на плоскости $[0, 1]^2$.
* **Uniform:** Независимые случайные величины с равномерным распределением $U(0, 1)$.
* **Lognormal:** Логнормальное распределение с тяжелым правым хвостом ($\mu=0, \sigma=1$).

### Сводные показатели задержки (Latency) и оптимальности на Spatial 2D

| $N$ | SciPy Hungarian (мс) | Google OR-Tools (мс) | Neural Sinkhorn (мс) | Optimality Gap Neural (%) | Feasibility (%) |
|---|---|---|---|---|---|
| **10** | 0.010 | 0.022 | 13.66 | 2.06% | 100.0% |
| **25** | 0.025 | 0.068 | 18.09 | 7.02% | 100.0% |
| **50** | 0.085 | 0.216 | 29.11 | 7.63% | 100.0% |
| **100** | 0.332 | 0.818 | 49.22 | 11.65% | 100.0% |
| **250** | 2.510 | 5.073 | 108.66 | 17.32% | 100.0% |
| **500** | 10.618 | 21.236 | 170.70 | 19.33% | 100.0% |
| **1000** | 54.251 | 94.979 | 308.45 | 24.56% | 100.0% |

### Ключевые выводы

1. **Превосходство скомпилированных C/C++ ядер:** Высокооптимизированные нативные алгоритмы (SciPy, OR-Tools) превосходят нейросетевую модель по единичной задержке (Single-item Latency) во всем диапазоне $N \le 1000$. Даже при $N = 1000$ решение находится за 54.2 мс на CPU, что укладывается в жесткий SLA $\le 100$ мс.
2. **Узкое место нейросетевого подхода:** Основная задержка нейросетевого пайплайна на GPU обусловлена не прямым проходом тензорных слоев, а этапом устранения коллизий и дискретной проекции (Bipartite Matching Rounding), требующим последовательных операций синхронизации.
3. **Пакетная обработка (Batch Throughput):** При экстремальных потоках независимых мелкоразмерных матриц ($N \le 50$, batch size $\ge 256$) параллельная обработка на GPU демонстрирует масштабируемость пропускной способности, однако точность снижается с ростом размерности.
4. **Рекомендованный архитектурный паттерн:** В высоконагруженных промышленных системах диспетчеризации рекомендовано применение гибридной схемы (Hybrid Fallback Pattern): первичный быстрый прогон точного алгоритма Джонкера-Волгенанта / аукциона с гарантией нулевого Optimality Gap, с переводом на эвристические и нейросетевые параллельные конвейеры исключительно в условиях экстремальной перегрузки очереди задач.

## Установка и запуск

### 1. Системные требования
* Python $\ge 3.10$
* Операционная система: Linux / Windows / macOS
* Рекомендуется видеокарта с поддержкой NVIDIA CUDA для запуска нейросетевых моделей

### 2. Установка зависимостей
```bash
git clone https://github.com/kiryshahaha/neuroVSalgo.git
cd neuroVSalgo
pip install -r requirements.txt
```

### 3. Запуск модульных тестов
```bash
python -m unittest discover tests
```

### 4. Проведение бенчмарка
Для быстрого тестирования на сокращенной сетке размерностей:
```bash
python run_benchmark.py --samples 20 --quick
```

Для проведения масштабного эксперимента на всей сетке ($N \in [10, 1000]$):
```bash
python run_benchmark.py --samples 25
```
Результаты сохраняются в директорию `results/`.

### 5. Обучение нейросетевой модели
```bash
python train.py --epochs 50 --batch_size 64
```
Или с продвинутым адаптивным расписанием коэффициента энтропии:
```bash
python train_advanced.py --epochs 100 --batch_size 64
```

### 6. Сборка научной статьи (.docx)
Для генерации чистового варианта статьи в формате Microsoft Word согласно ГОСТ:
```bash
python make_docx_article.py
```
