# ИНСТРУКЦИЯ ПО ОБУЧЕНИЮ НЕЙРОСЕТЕВОГО МОДУЛЯ

Нейросетевая модель построена на базе перестановочно-эквивариантного энкодера **Edge-MLP** и слоя **Синхорна-Кноппа**.  
Обучение проводится по схеме **Knowledge Distillation** (Учитель: Google OR-Tools).

---

## 1. Подготовка окружения (Установка PyTorch)

У вас установлена мощная дискретная видеокарта **NVIDIA GeForce RTX 4070 (12 ГБ VRAM)**.  
Для запуска нейросети на максимальной скорости рекомендуется установить PyTorch с поддержкой CUDA.

### Установка с поддержкой GPU (CUDA 12.4+):
В терминале PowerShell выполните:
```powershell
pip install torch --index-url https://download.pytorch.org/whl/cu124
```
*(Если по какой-то причине CUDA не нужна, можно поставить CPU-версию: `pip install torch`)*.

## 2. Архитектура нейросетевого пайплайна

1. [`src/models/edge_mlp.py`](file:///c:/Users/Кирилл/Desktop/nauchka/src/models/edge_mlp.py):
   - Оценивает относительную выгоду каждой ячейки $(i, j)$ с учетом локальной цены, среднего по строке исполнителя, среднего по столбцу задачи и глобального среднего матрицы.
   - **Инвариантна к размерности $N$** (обучается на $N=40$, а применяется на любых $N$ от 10 до 1000).
2. [`src/models/sinkhorn.py`](file:///c:/Users/Кирилл/Desktop/nauchka/src/models/sinkhorn.py):
   - Слой дифференцируемой нормализации в log-пространстве (LogSumExp).
   - Приводит матрицу к дважды стохастическому виду (суммы по строкам и столбцам $\approx 1$).
3. [`src/models/decoder.py`](file:///c:/Users/Кирилл/Desktop/nauchka/src/models/decoder.py):
   - Быстрый векторизованный жадный проекционный декодер.
   - Устраняет дробные вероятности и формирует строгую перестановку $X \in \mathcal{P}_N$.
4. [`src/solvers/neural_solver.py`](file:///c:/Users/Кирилл/Desktop/nauchka/src/solvers/neural_solver.py):
   - Обертка `NeuralSolver`, реализующая единый интерфейс `BaseSolver`.
   - Автоматически синхронизирует CUDA-потоки и поддерживает пакетную обработку батчей.

## 3. Запуск обучения

Для запуска обучения используется готовый скрипт [`train.py`](file:///c:/Users/Кирилл/Desktop/nauchka/train.py).

### А. Быстрый проверочный запуск (за 30 секунд):
Для быстрой проверки работоспособности на небольшом числе матриц:
```powershell
python train.py --epochs 5 --train_size 300 --val_size 60 --n 30
```

### Б. Полноценное качественное обучение (для диплома / научной статьи):
Генерирует 3000 обучающих задач, размечает их эталоном OR-Tools и обучает модель за 20 эпох:
```powershell
python train.py --epochs 20 --batch_size 64 --train_size 3000 --val_size 500 --n 40
```
*На RTX 4070 обучение займет около 1–2 минут!*

---

## 4. Параметры скрипта `train.py`

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `--epochs` | `20` | Количество эпох обучения |
| `--batch_size` | `64` | Размер пачки матриц, обрабатываемой за один шаг GPU |
| `--train_size` | `3000` | Количество синтетических матриц для обучения |
| `--val_size` | `500` | Количество матриц для валидации и контроля переобучения |
| `--n` | `40` | Размерность матрицы $N \times N$, на которой учится модель |
| `--lr` | `0.001` | Скорость обучения (Learning Rate) оптимизатора AdamW |
| `--save_path` | `checkpoints/best_model.pt` | Файл сохранения лучших весов модели |

---

## 5. Что происходит после завершения обучения?

В каталоге `checkpoints/` появится файл **`best_model.pt`** (~50 КБ).  
Этот файл содержит обученные веса. После этого можно запускать финальный сравнительный бенчмарк:
* Сравнивать время работы `OR-Tools vs NeuralSolver` на размерах $N \in \{10, 25, 50, 100, 250, 500, 1000\}$.
* Вычислять процент отклонения стоимости от идеала (Optimality Gap).
